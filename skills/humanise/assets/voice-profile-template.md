## How to read this profile

This is a working document. The sections below describe patterns mined from the user's own writing. When humanising a draft:

- **Cross-register signatures** → apply regardless of document formality
- **Casual-only markers** → apply only when the document is casual; strip for business/formal
- **Anti-vocabulary** → never introduce these words into a rewrite, even if the source draft uses them

Be specific with examples; vague notes like "hedges sometimes" aren't actionable.
