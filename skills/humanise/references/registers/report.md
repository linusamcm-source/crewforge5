# Register pack: report

Internal report, briefing document, postmortem, analysis doc.

**Exemplar**: Register 3 in [../business-register-exemplars.md](../business-register-exemplars.md).

**Conventions**
- Summary up top: what happened, magnitude, cause, purpose of doc.
- Prose paragraphs where the argument is connected; bullets only for genuinely parallel items.
- Specific times, percentages, durations — no "significant impact" handwaving.
- Headers in sentence case.
- Minimal idiom; voice comes through in rhythm, argument shape, and what gets cut.

**Tell emphasis**: generic closing sentences per paragraph, symmetric pros/cons lists, uniform paragraph structure, "it's important to note".
