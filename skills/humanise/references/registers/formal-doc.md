# Register pack: formal document

Proposal, tender, board paper, client deliverable — the most buttoned-up register.

**Exemplar**: Register 4 in [../business-register-exemplars.md](../business-register-exemplars.md).

**Conventions**
- Plain confident prose. No "we believe", "we will endeavour to", "our team is excited to".
- Commit to scope; flag exclusions explicitly.
- No idiom. AU English shows up in spelling only (colour, centre, -ise, "while" not "whilst").
- Voice transfers through structure and argument shape only — see the structural tier in [../voice-tiers.md](../voice-tiers.md).
- Audience check: proposal to an American client → AU spelling only if the user's context warrants it (see what-not-to-do).

**Tell emphasis**: over-balanced both-sidesing, "we would be delighted", tricolon adjectives, padding with definitions.
