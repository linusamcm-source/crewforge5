# Voice profile edge cases

## Fallback when session_info is unavailable

If `session_info` isn't available in the current environment, fall back: ask the user to paste 3–5 samples of their own writing (chat messages, emails, Slack, whatever's unmediated).

## Step 4: Optional refresh

If the user asks to refresh or rebuild, re-mine recent sessions. If they just want to tweak, point them at the file to edit directly.
