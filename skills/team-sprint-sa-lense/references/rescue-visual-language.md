# Rescue Visual Language (shared)

Shared by team-sprint-sa-lense (technical assessment) and team-sprint-pm-lense
(PM assurance). Both skills MUST use this identically — same palette, effort
tags, and shapes in diagrams, gap-analysis tables, and written findings — so
the two outputs read as one deliverable.

## Severity colour code

Three states only — resist a fourth:

- **Green** — healthy / present, keep as-is
- **Amber** — fragile / thin, needs rework
- **Red** — broken or missing

Use the exact same palette in tables, written findings, and any diagrams so
the diagram and the summary reinforce each other.

## Effort channel

Keep colour for severity; use a separate channel for effort:

- Preferred: a small **T-shirt-size tag** (S / M / L) on each flagged item.
  Survives being screenshotted into a slide deck. A red item with an S tag is
  a quick win — flag these for early momentum in a rescue.
- Alternative: **border weight** (thin = low effort, thick = heavy). Purely
  visual but subtler and easier to misread.

## Shapes

Diagrams render via the draw.io skill. Keep shapes identical across both
skills' diagram sets — same node shapes for systems/artefacts, same connector
styles, same annotation treatment — so the technical and PM outputs are
visually one system.

## Prioritisation Grid (bridge from diagnosis to plan)

Plot severity (vertical) against effort (horizontal). Every flagged item lands
in exactly one quadrant:

- **High severity, low effort** — do it now. Quick wins that stop the bleeding
  and buy credibility in the first fortnight (e.g. stand up a RAID log). Lead
  with these.
- **High severity, high effort** — plan it properly. Big rebuilds (e.g.
  re-baseline the whole schedule with the team) go on the roadmap with funding
  and sequencing, not the to-do list.
- **Low severity, low effort** — tidy up when convenient. Housekeeping around
  the big stuff.
- **Low severity, high effort** — park it, maybe never. The trap where teams
  burn months on something that barely moves the needle.

The grid becomes the sequencing story — the bridge between diagnosis and
recovery plan.
